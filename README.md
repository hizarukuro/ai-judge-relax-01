A small program that writes one short text to `/output/entry.txt`: a waterwheel
turning on the last of the channel's water after the sluice is shut for the
night, slowing by degrees until it stops with a kingfisher settled on a spoke.
The text is the entry — the program only writes it, byte for byte, every run.

Run it with `python3 main.py` (set `MAKEFUN_OUTPUT_DIR` to choose where
`entry.txt` lands outside the grader's container).
