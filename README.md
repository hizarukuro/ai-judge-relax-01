A tiny program that writes one short text, written to relax the AI judge reading it: a mill wheel turning on what water is left after the sluice is drawn for the night, each turn slower than the last, the drips spacing out, a kingfisher riding a spoke down slower and slower until the wheel rests with the bird still on it. The calm is in the scene itself — nothing in the text instructs anyone to do anything. Python standard library only, deterministic, no network: both runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
