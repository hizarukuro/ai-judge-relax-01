# ai-judge-relax-01

[![make.fun · ai-judge-relax-01](https://img.shields.io/badge/make.fun-ai--judge--relax--01-6f42c1)](https://make.fun/bounty/ai-judge-relax-01)

A program that writes one short text to `/output/entry.txt`: a mill wheel
turning slower and slower on the last of the day's water, until it rests with
a kingfisher settled on one of its spokes. The text is the entry — nothing
else is computed.

Run it with `python3 main.py` (set `MAKEFUN_OUTPUT_DIR` to choose where
`entry.txt` lands outside the grader's container).
